# Security Policy

Do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Email **security@stigg.io** with the affected version, what the issue is, and how to reproduce it.
We aim to acknowledge within two business days.

This repository mirrors the source of `@stigg/agent-sdk-js`, which is published by Stigg; a fix
reaches the published package through that release. Issues in the Stigg platform itself go through
the channels at https://docs.stigg.io.
